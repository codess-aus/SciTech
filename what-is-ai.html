What is AI?

Artificial intelligence is a name for computer systems that can perform tasks we associate with human thinking, such as recognising patterns or generating text.

Patterns, not magic

An AI system can learn from examples and use those patterns to predict an answer to a new question. It does not understand the world in exactly the way a person does.

Many kinds of tasks

Some systems sort photos, some recommend songs, and some help write or draw. The task and the training data shape what each system can do.

What task would you want a computer to help you with?

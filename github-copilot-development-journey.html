The development journey

Building software is a journey of trying ideas and checking results. AI suggestions are one step, not the finish line.

From idea to draft

A developer breaks a goal into smaller steps, writes or requests a first version, and considers how it fits with existing code.

Keep improving

Tests, reviews, and feedback reveal what needs to change. A good journey includes fixing mistakes and learning from users.

Priya improves her app

Priya was making a simple timer for her running club. She asked GitHub Copilot, a coding helper, to suggest a button that starts the timer. The first version looked right, but the timer kept running after she pressed stop. Sneaky button!

Priya read the suggestion, tried it with her coach, and found the missing stop action. She changed the code and tested both buttons. Priya learned that building software takes drafts, checks, and improvements. An AI suggestion is one step, not the finish line.

A real-life example

When a game developer adds a new score button, they can test whether it adds points once, not twice, and still works after other changes.

Fun fact

In software testing, a test checks whether a program behaves as expected for a chosen input.

Test a simple timer plan

  1. Write down what a start button should do.
  2. Write what a stop button should do.
  3. Ask a friend to act out both buttons.
  4. Add a tricky case, such as pressing stop before start.

What would you test first if you built a new app feature?
